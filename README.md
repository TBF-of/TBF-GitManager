# 🔥 TBF-GitManager — Git-менеджер для Termux

> **Git Manager for Termux / Linux — by TBFPUMBA**

Простий та зручний консольний Git-менеджер для щоденної роботи з репозиторіями.

---

## 🚀 Можливості

- 📊 **Статус** — перегляд змінених файлів
- ⚡ **Швидкий коміт** — `git add .` + коміт
- 🚀 **Пуш на GitHub** — відправка змін
- 📜 **Логи** — останні 5 комітів
- 🎉 **Ініціалізація** — `git init`
- 📍 **Інформація** — поточна гілка та шлях

---

## ⚡ Встановлення

```bash
git clone https://github.com/TBF-of/TBF-GitManager.git
cd TBF-GitManager
pip install -r requirements.txt
python3 tbf_git.py
```

---

📦 Залежності

```bash
pip install rich
```

📌 Як користуватися

1. Запустіть скрипт: python3 tbf_git.py
2. Оберіть потрібну дію з меню:
   · 1 — перевірити статус
   · 2 — зробити швидкий коміт
   · 3 — запушити на GitHub
   · 4 — подивитися логи
   · 5 — ініціалізувати новий репозиторій
   · 0 — вихід
